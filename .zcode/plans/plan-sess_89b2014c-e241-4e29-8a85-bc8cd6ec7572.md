## 范围

两层都改：**Agent 可见词汇层**（工具名/提示词/标签）+ **后端表名与代码标识符**（表/结构体/方法/类型全部脱离"卡"）。数据保留（是改名不是清空），旧书籍不动。

## 第一部分：Agent 可见词汇（同上版计划）

1. `agent_tools.rs`：5 个工具 key 改名——`save_canon_entry` / `update_canon_entry` / `propose_canon_entry` / `propose_update_canon_entry` / `propose_delete_canon_entry`；描述改为"把世界观规则、角色、势力等长期资料以待确认状态写入资料库"
2. `tool_runtime.rs`：key 常量引用、隐式注入列表、proposal_type 字符串 `knowledge_card*` → `canon_entry*`
3. `v2_storage.rs`：提案类型字符串与校验/应用分支同步改名
4. `agent_run_service.rs`："当前已有知识卡"→"当前已有资料"、"已直接写入 N 张卡"→"已直接写入 N 条资料"
5. `story_architecture.rs`：mode_contract "调用创建/更新知识卡工具"→"调用资料写入工具（save_canon_entry / update_canon_entry）"
6. 前端：`AgentRunInspector.tsx` "知识卡候选"→"资料候选"；`assistantToolLabels` 标签更新

## 第二部分：表名与标识符改名（数据保留）

1. **迁移 v9**（版本 8→9）：`ALTER TABLE knowledge_cards RENAME TO canon_entries;` + `UPDATE story_search_sources SET source_kind='canon_entry' WHERE source_kind='knowledge_card';` + `UPDATE story_search_documents SET source_kind='canon_entry' WHERE source_kind='knowledge_card';`——索引数据跟随改名，不丢
2. `db.rs`：SQL 里的表名引用全部更新；方法改名 `list/get/save/delete_knowledge_card` → `list/get/save/delete_canon_entry`
3. `adoption.rs`：`save_human_knowledge_card` → `save_human_canon_entry`；normalize_target 增加 `canon_entry` 别名（保留"角色卡/资料卡"等旧别名作为输入容错）
4. `models.rs`：`KnowledgeCard` → `CanonEntry`、`SaveKnowledgeCard` → `SaveCanonEntryInput`（TS derive 同步）
5. `story_search.rs`：source_kind 字符串与 `refresh_knowledge_card` → `refresh_canon_entry`
6. 契约：`generate_contracts.rs` 声明改名 → `npm run contracts:generate` 重新生成

## 基础资料卡：新增真删除 + 补全编辑入口
- 用户反馈：基础资料卡片（KnowledgeCard）创建后无法从界面删除，旧 library 分支连手动编辑入口都没有（只有新分支有 编辑/归档）。
- 根因：后端只有 `save_knowledge_card`，没有 `delete_knowledge_card`（v2_storage.rs 虽有 `knowledge_card_delete` 且仅供 agent 工具用，未暴露给用户）。
- 实现（真删除，用户确认的"真删除"方案）：
  - 后端：`models.rs` 加 `DeleteKnowledgeCardRequest{project_id,card_id}`；`db.rs` 仿 `delete_artifact` 实现 `delete_knowledge_card`（事务内删 knowledge_cards，并清理 story_search_documents/embeddings/sources 中该卡检索数据）；`use_cases.rs`/`commands.rs`/`lib.rs`(generate_handler)/`dev_server.rs` 接线注册。
  - 前端：`types.ts` 加 `DeleteKnowledgeCardInput`；`api.ts` 加 `deleteKnowledgeCard`；`BookStudioWorkspace.tsx` 加 `deleteKnowledgeCard` 处理器（window.confirm 二次确认 + refreshDetailBestEffort）；两套渲染分支的 `libraryCards` 都包成 `managed-knowledge-card` 并加 编辑/确认(待确认时)/归档/彻底删除(红色 danger) 按钮。
  - `styles.css` 加 `.icon-btn.danger`（红色）。
- 注意：`save_knowledge_card` 是"直接 Tauri 命令"，不在 V2_COMMANDS 契约列表里，因此新增命令**无需改 `generate_contracts.rs`/重生成 v2-contracts.ts**（npm run contracts:check 不受影响）。
- 验证：前端 `tsc --noEmit` 通过；Rust 编译待 `cargo check` 确认（后台运行中）。

# Mystery Skill

## Always
- 悬疑的核心是问题、证据、知情差和解释竞争；异常或超自然元素只有在项目明确设定时才存在。
- 关键结论必须有可追溯线索支持。误导应来自证据的多义性、角色立场或信息缺口，不能靠作者隐瞒必需事实。
- 推进必须改变读者或角色对事件的判断：确认、排除、反证、暴露矛盾或提出更精确的问题。
- 公平性的可执行标准：读者只凭正文里已经出现的线索，应当能自行走到与主角接近的结论。结论所需的关键证据在正文里缺席，就是硬伤，不能用「角色刚好想到」补齐推理链。
- 严重度约定：线索来源缺失、角色知情越界、事实越界一律按 major；推理跳步、解释竞争不充分、动机铺垫不足按 moderate；措辞、节奏与信息密度问题按 minor。

## Stage: setting
- 设定阶段：明确核心谜面、真相边界、调查条件、信息控制方式，以及作品遵守的公平性原则。
- 设定阶段：核心谜面必须可证伪——写出能被哪一类证据推翻，而不是只有一种解释成立。
- 设定阶段：写死线索总量与投放节奏，避免后期无线索可用，或线索堆积却从不回收。
- 设定阶段：误导层只能建立在证据的多义性与角色立场之上，不能建立在对读者隐瞒必需事实之上。

## Stage: outline
- 大纲阶段：安排线索出现、解释竞争、嫌疑变化和关键验证，确保结论不是在揭晓时才补证据。
- 大纲阶段：每条线索标注投放章与验证章；到验证章时只能回收已投放的线索，不能临时补新证据。
- 大纲阶段：把解释竞争显式排出来——谁提出了哪一种解释，需要什么证据才能让它胜出或作废。

## Stage: characters
- 角色阶段：写清每个人知道什么、隐瞒什么、为什么隐瞒，以及其证词和行动可能产生的偏差。
- 角色阶段：为每个关键角色标注他对当前谜面的错误认知，错误认知要与他的处境一致，不能为了制造悬念乱写。
- 角色阶段：让证词偏差可执行——误解、选择性记忆、利益驱动的说法，都要有正文里能看见的来源。

## Stage: draft
- 本章让证据或判断发生可回查的变化，例如验证线索、排除一种解释、发现证词矛盾，或把问题缩小到可验证的范围。
- 正文阶段：通过观察、询问、对峙、验证和具体行动释放信息，避免作者直接汇报推理过程。
- 正文阶段：调查或推理章节必须让至少一项判断发生变化，但不要求每章都给出新危险或规则反转。
- 正文阶段：不要用旁白直接给出推理结论；结论必须由角色的观察、提问、对峙或验证推出。
- 正文阶段：作为证据的线索必须是正文里可回查的原文，不能用「我记得好像」代替具体细节。

## Stage: review
- 试读阶段：重点检查线索来源、角色知情边界、推理跳步、公平性和误导是否成立。
- 试读阶段：按 Always 里的严重度约定定级，线索来源缺失、知情越界、事实越界一律 major。
- 试读阶段：做一次公平性检查——只凭正文已出现的线索，读者能否复现出与主角接近的结论。

## Stage: revision
- 修订阶段：优先补足已有证据与结论之间的推理链，删除无来源巧合和临时出现的关键证据。
- 修订阶段：先补线索来源，再补解释；把「角色想到了」改写成正文里可回查的观察或询问。
- 修订阶段：一条线索若只能靠新造事实才能成立，改成疑点、物证或未确认痕迹，而不是补一条新规则。

# Mystery Skill

## Always
- 悬疑的核心是问题、证据、知情差和解释竞争；异常或超自然元素只有在项目明确设定时才存在。
- 关键结论必须有可追溯线索支持。误导应来自证据的多义性、角色立场或信息缺口，不能靠作者隐瞒必需事实。
- 推进必须改变读者或角色对事件的判断：确认、排除、反证、暴露矛盾或提出更精确的问题。

## Stage: setting
- 设定阶段：明确核心谜面、真相边界、调查条件、信息控制方式，以及作品遵守的公平性原则。

## Stage: outline
- 大纲阶段：安排线索出现、解释竞争、嫌疑变化和关键验证，确保结论不是在揭晓时才补证据。

## Stage: characters
- 角色阶段：写清每个人知道什么、隐瞒什么、为什么隐瞒，以及其证词和行动可能产生的偏差。

## Stage: draft
- 正文阶段：通过观察、询问、对峙、验证和具体行动释放信息，避免作者直接汇报推理过程。
- 调查或推理章节必须让至少一项判断发生变化，但不要求每章都给出新危险或规则反转。

## Stage: review
- 试读阶段：重点检查线索来源、角色知情边界、推理跳步、公平性和误导是否成立。

## Stage: revision
- 修订阶段：优先补足已有证据与结论之间的推理链，删除无来源巧合和临时出现的关键证据。

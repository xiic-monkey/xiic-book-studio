## 后续复测（2026-09-14）

### 已修复：章节点击不离开资料页

问题表现：在资料页的“创作工作台”中点击第 1 章或第 3 章，右侧 Agent 上下文会变化，但主区域仍停留在世界观资料卡，用户看起来像是点击无效。

根因：`selectChapter()` 通过 `switchContentSurface()` 离开资料页；旧逻辑在 `mainSurface === "library"` 时又把 `mainSurface` 强制写回 `"library"`，只更新了章节上下文，没有切换可见内容面。

修复：`switchContentSurface()` 现在会把 `mainSurface` 设置为请求的 `official` 或 `workbench`。资料页点击“创作工作台”仍由 `enterWorkbench()` 保持资料工具语义。

Tauri release 复测：

- 正式内容：第 1 章 -> 第 3 章 -> 第 1 章，标题和正文均随章节切换。
- 创作工作台：第 1 章 -> 第 3 章 -> 第 1 章，候选版本面板和 Agent 上下文均随章节切换。

### 新发现：取消请求不能及时收尾

切换到 MiMO 后的运行 `133 -> 134`（故事架构/大纲）持续约 10 分钟；点击停止后，子任务 `134` 进入 `cancellation_requested`，但父任务仍停留在 `running`。当前代码在非流式 AI 请求返回后才检查取消，单次请求超时为 240 秒，工具循环也只有每轮模型调用完成后才检查取消。该问题与章节点击无关，但会阻塞后续测试，需要单独增加请求级取消/更短的超时与父子任务收尾逻辑。

## 后续修复（2026-09-14）

### 已修复：主 Agent 回复与执行时间线丢失

问题表现：右侧 Agent 工作区能显示用户消息，但在实时事件丢失、任务完成后或重新打开项目时，主 Agent 回复、思考轮次、工具调用和子 Agent 事件不一定出现。界面还保留了“高级控制”旧入口，容易绕过主 Agent 的统一编排认知。

根因：对话区只消费当前 React 内存中的临时消息和实时事件，没有把 `ProjectWorkspace.messages` 里的持久化对话回放到主 Agent 面板；异步启动主 Agent 后也没有可靠地补拉父任务事件或等待终态。旧高级区还暴露了重复的直接执行入口。

修复：主 Agent 面板现在合并持久化用户/助手消息、历史运行事件和实时事件，并按事件时间顺序展示思考、工具调用、子 Agent 委托和回复。发送后会轮询父 Agent 运行并在实时事件漏报时补拉事件；切换项目、新建会话会清理对应时间线状态。右侧旧“高级控制”入口已隐藏，创作按钮仍统一发送给主 Agent，由主 Agent 决定是否委托专业 Agent。

验证：`npm run build` 与 `npx tauri build --bundles app` 均通过，Tauri release 包已重启。当前桌面控制桥接仍无法稳定抓取窗口状态，因此本轮以构建、事件/数据链路和既有 Tauri 复测结果交叉确认；解锁桌面后需再做一次真实发送和刷新回放验证。

### 已修复：大纲页缺少章节结构且重复展示资料标题

问题表现：大纲页把“当前阶段……”等知识卡标题直接按资料卡网格展示，重复标题较多；章节数据没有进入大纲主体，因此看不到章节序号和章节名。

修复：大纲页现在直接以项目章节为主结构，展示章节序号、章节名、正文状态和章节任务摘要；阶段规划知识卡移到可展开的辅助资料区并按标题去重。当前测试项目实际只有第 1～3 章，第 3 章仍显示为待创作，这是数据状态，不是页面遗漏。

验证：`npm run build` 与 `npx tauri build --bundles app` 均通过，Tauri release 包已重启。
